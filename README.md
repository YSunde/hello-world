# КБ-13 — сайт креативного бюро

> **Основной сайт (v3 «Молния-лента»)** — ветка `claude/red-lightning-effects-design-w7gxvc`, корень https://ysunde.github.io/hello-world/. Альтернатива v2 «Гроза на бумаге» — https://ysunde.github.io/hello-world/v2/ (ветка `claude/kb13-v2-storm`).

Одностраничный сайт: белое поле, крупный голос, красный разряд. Статика без зависимостей — готова для GitHub Pages (`index.html` в корне). **Работает без интернета и без сервера:** скачайте папку и откройте `index.html` двойным кликом, или возьмите один файл из [`готовое/`](готовое/).

- Дизайн-система и правила эффектов — [DESIGN.md](DESIGN.md)
- Концепт и промпт видео-визитки — [docs/VIDEO_PROMPT.md](docs/VIDEO_PROMPT.md)

## Как открыть

**Постоянная ссылка (рекомендуется): GitHub Pages.** Сайт уже в ветке `master`. Один раз включите: репозиторий → Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `master`, папка `/ (root)` → Save. Через 1–2 минуты сайт будет по адресу **https://ysunde.github.io/hello-world/** — эту ссылку можно отправлять, она работает всегда.

**Codespaces.** Открыть одной ссылкой: **https://codespaces.new/YSunde/hello-world?quickstart=1** → Create codespace (если он уже есть — откроется существующий). Через 1–2 минуты сервер запустится сам на порту 8013 и сайт откроется в новой вкладке (или нажмите «Open in Browser» во всплывающем уведомлении; либо вкладка **Ports** внизу → строка «Сайт КБ-13» → значок глобуса). Порт 8013 при старте пытается сам стать публичным. Если в колонке Visibility он всё ещё Private: Ports → правый клик по 8013 → Port Visibility → **Public**. Ссылка для отправки: правый клик по 8013 → Copy Local Address (вида `https://…-8013.app.github.dev`). Ссылка живёт, пока Codespace запущен (засыпает примерно через 30 минут без активности; снова открыть — той же ссылкой выше). Если сайт не открылся, в терминале Codespace выполните `node scripts/serve.mjs`.

**На своём компьютере — без сервера и интернета.** Скачайте проект (Code → Download ZIP), распакуйте и откройте `index.html` двойным кликом. Скрипты собраны в один обычный файл `assets/js/site.js`, шрифты встроены в `assets/css/fonts.css`, поэтому всё работает прямо с диска (`file://`). Ещё проще — один файл `готовое/KB13-v3-latest.html`, внутри которого есть всё, включая видео.

Сервер нужен только для разработки (по желанию): `node scripts/serve.mjs` → http://localhost:8013/.

## Структура

```
index.html               готовая страница (генерируется)
privacy.html             Политика обработки персональных данных (генерируется)
consent.html             Согласие на обработку персональных данных (генерируется)
requisites.html          Реквизиты ИП (генерируется)
robots.txt, llms.txt     для поисковиков и ИИ-ассистентов (генерируются; sitemap.xml — когда задан site_url)
content.ru.json          весь маркетинговый текст (из прототипа, без правок)
legal.ru.json            тексты политики и согласия (документы заказчика) + подписи баннера cookie
site.config.json         контакты, реквизиты ИП, счётчики, документы, видео, адреса приёма заявок, чат
assets/
  css/main.css           токены, сетка, все блоки, адаптив 320–1440+
  css/fonts.css          шрифты, встроенные в CSS (генерируется)
  js/site.js             все скрипты одним обычным файлом (генерируется из модулей ниже)
  js/lightning.js        генерация геометрии разряда
  js/storm.js            удары, искры, подпалины, вспышка
  js/ribbon.js           молния-лента через всю страницу
  js/main.js             поведение: меню, слайдер, аккордеон, окна, формы, эффекты
  js/cookies.js          cookie-баннер; Метрика и VK Pixel — только после согласия
  js/docs.js             документы внутри одного файла (готовое/)
  js/doc-main.js         скрипт страниц документов → doc-site.js
  img/                   изображения WebP с прозрачностью + IMAGE_MAP.json (13-team-* — фото команды)
  icons/                 17 SVG-иконок, icons.json (источник), sprite.svg
  brand/                 logo.svg, icon.svg (оригиналы), og.jpg — превью ссылки 1200×630
  fonts/                 Sofia Sans Extra Condensed, Manrope (OFL)
  video/                 видео-визитка MP4 + постер
scripts/
  build.mjs              content.ru.json + site.config.json → index.html, site.js, fonts.css
  bundle.mjs             сборка модулей assets/js в один site.js (без зависимостей)
  seo.mjs                микроразметка schema.org, Open Graph, robots.txt, sitemap.xml, llms.txt
  pack-standalone.mjs    весь сайт в один HTML-файл (папка готовое/)
  check-content.mjs      сверка текста страницы с content.ru.json и документов с legal.ru.json
  render-video.mjs       покадровый рендер видео (Playwright + ffmpeg)
  serve.mjs              локальный сервер одной командой (без зависимостей)
.devcontainer/           настройка Codespaces: сервер стартует автоматически
video/                   сцена и таймлайн видео-визитки
```

## Команды

```bash
node scripts/build.mjs            # собрать index.html, assets/js/site.js, assets/css/fonts.css
node scripts/check-content.mjs    # проверить, что все строки и цены на месте
node scripts/serve.mjs            # посмотреть локально: http://localhost:8013/
node scripts/pack-standalone.mjs готовое/KB13-v3-latest.html   # один файл (только node; ffmpeg — по желанию, для сжатия видео)
node scripts/render-video.mjs     # пересобрать видео (нужны playwright и ffmpeg с libx264/libwebp)
```

Правки текста — только в `content.ru.json`, данных интеграций — только в `site.config.json`; затем `node scripts/build.mjs`. Все скрипты сборки работают без интернета (нужен только Node.js 18+).

## Что ещё не подключено (честные состояния на сайте)

Сайт ничего не выдумывает: где данных нет, показано понятное состояние.

| Что | Где задать | Сейчас на сайте |
| --- | --- | --- |
| Телефон для «телефонировать» | `site.config.json → phone` | панель «номер ещё не задан» + переход к форме |
| Телефоны, почта, соцсети | `contacts.phones / emails / socials` | «появятся после передачи данных» |
| 3 документа пакетов и полное КП | `downloads.*` | кнопки сообщают «файл ещё не загружен» |
| Приём заявок (форма, окно «13 минут», мини-бриф) | `endpoints.contact`, `endpoints.lead`, `endpoints.brief` | демо-режим: «заявка не отправлена», данные остаются в форме |
| Чек-лист «13 вопросов к себе» | `endpoints.checklist` + файл | «доставка не подключена — письмо не отправлено» |
| Чат | `chat.provider` | панель «чат ещё не подключён» + переход к форме |
| Живое видео команды | `video.url / poster / title` | стоит моушн-концепт визитки |
| E-mail для обращений по персональным данным | `legal.pd_email` | в политике и согласии — письменное обращение на почтовый адрес ИП |
| Боевой адрес сайта | `site_url` | в политике — «сайт, на котором размещена Политика»; в микроразметке ссылки относительные, нет canonical и sitemap.xml |
| Яндекс Метрика / VK Pixel | `analytics.yandex_metrika_id / vk_pixel_id` | не ставятся; баннер cookie уже спрашивает согласие |
| Согласие на рекламную рассылку (38-ФЗ) | `legal.mailing_consent` | не собирается: чек-лист — не подписка, так и написано у галочки |
| Лицензированный Druk Condensed | `assets/fonts` + `main.css` | резерв Sofia Sans Extra Condensed 900 |

Формулировки из прототипа, требующие подтверждения заказчика, сохранены как есть — список в `content.ru.json → editorial_review`.

## Документы и согласия (152-ФЗ)

- **Оператор и исполнитель** — ИП Моисеева Ульяна Львовна: `site.config.json → legal.operator` (ИНН, ОГРНИП, адреса, банк). Сборка проверяет контрольные цифры ИНН, ОГРНИП и счёта и что в текстах политики и согласия стоят те же ИНН/ОГРНИП.
- **Страницы:** `privacy.html` (политика с содержанием), `consent.html` (согласие — отдельным документом, как требует ст. 9 152-ФЗ с 01.09.2025), `requisites.html` (с кнопкой «Скопировать реквизиты»). Перелинковка: вкладки между документами, «На главную», подвал на всех страницах (ИП, ИНН, ОГРНИП, три документа, «Настройки cookie», «не является публичной офертой»).
- **Формы** (обратная связь, «13 минут», чек-лист, мини-бриф): обязательная, не отмеченная заранее галочка «Я даю согласие на обработку персональных данных» со ссылкой на текст согласия и политику (открываются в новой вкладке — данные в форме не теряются). Без галочки форма не отправляется. С заявкой уходят `pd_consent`, редакция документа, время и страница — доказательство согласия.
- **Cookie:** баннер при первом визите — «Принять все» / «Только необходимые» / «Настроить» (аналитические и маркетинговые отдельно); выбор меняется в подвале. Метрика с Вебвизором и VK Pixel подключаются только после согласия; при отзыве их cookie удаляются. Поля форм помечены `ym-disable-keys ym-hide-content` — Вебвизор не записывает их содержимое (п. 8.4 политики).
- **Один файл (`готовое/`):** документы внутри файла — ссылка открывает документ вместо страницы, «назад» возвращает на то же место.
- **Править тексты документов** — в `legal.ru.json` (только с юристом), затем `node scripts/build.mjs` и `node scripts/check-content.mjs`.

## Микроразметка (SEO / GEO)

`scripts/seo.mjs`, всё — из тех же данных, что и страница, без выдуманных полей:

- **JSON-LD (schema.org)** на главной: `Organization` (КБ-13, юр. лицо — ИП, ИНН, ОГРНИП, регион, направления, каталог пакетов), `WebSite`, `WebPage`, три `Service` с `Offer` (цена в рублях, формат, срок), `FAQPage` («За и против»), `ItemList` кейсов, `VideoObject` (видео-визитка). На документах — `WebPage` / `AboutPage` (реквизиты) с датой редакции и `BreadcrumbList`.
- **Превью ссылок:** Open Graph и Twitter Card с картинкой `assets/brand/og.jpg`; заголовок страницы с направлениями.
- **Для ИИ-поиска (GEO):** `llms.txt` — бюро, пакеты с ценами и сроками, сводная таблица, кейсы, «За и против», документы; `robots.txt` открывает сайт всем, в том числе ИИ-краулерам.
- **С доменом** (`site_url`): абсолютные ссылки в разметке, `canonical`, `og:url`, `sitemap.xml` и строка `Sitemap:` в robots.txt появляются сами при сборке.
- `node scripts/check-content.mjs` проверяет разметку: валидный JSON, обязательные поля, ссылки внутри графа, цены и вопросы — те же, что на странице.

## Изображения

Люди на сайте — фото команды заказчика (`13-team-1…4`: вырезка фона, ч/б, растворённые срезы кадра, красный контур отдельным слоем `-glow`). Предметы в пакетах — постановочные сгенерированные кадры, не кейсы бюро. Старые постановочные персонажи остались только в исходнике видео-визитки (`video/img`). У предметных кадров фон удалён (rembg / isnet-general-use), результат проверен вручную; кадрирование совпадает с исходниками, поэтому координаты из `IMAGE_MAP.json` действуют.

## Проверки, выполненные перед выкладкой

- 1440 / 1024 / 768 / 390 / 320 px: без горизонтальной прокрутки body, таблица прокручивается внутри, первая колонка ≤ 30%.
- 42 автоматических сценария (Playwright): клавиатура, skip-link, слайдер, аккордеон, окна (Esc, фокус, возврат фокуса), валидация и демо-состояния форм, скачивания, чат, телефон, «Наверх», видео, меню, reduced motion, без ошибок консоли.
- Без JavaScript всё содержимое читается.
- `check-content.mjs`: 126 строк и все цены совпадают с `content.ru.json`.
