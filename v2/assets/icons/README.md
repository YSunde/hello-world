# Иконки КБ-13

17 иконок, перерисованы на строгой сетке: viewBox 48×48, живая зона 6–42, штрих 2,5, квадратные концы, острые углы. Чёрный каркас (`currentColor`) и один красный смысловой штрих (`.i-accent`, цвет из `--icon-accent`), который не накладывается на чёрные линии.

Источник — `icons.json` (пути base / accent). Из него `scripts/build.mjs` строит инлайн-спрайт и инлайновые иконки в кнопках; отдельные `*.svg` — для дизайнеров.

| Иконка | Смысл | Анимация (однократно) |
| --- | --- | --- |
| contract-shield | результат по договору | галочка прорисовывается, 260 мс |
| parallel | дополняем ваш отдел | вторая стрелка прорисовывается, 300 мс |
| new-angle | новое решение | стрелка смещается на 2 px и обратно, 360 мс |
| dialogue | начинаем с разговора | штрих проявляется 0,45→1, 280 мс |
| time | бережём время | стрелка секундомера поворачивается на 12°, 420 мс |
| results | работы и результат | линия тренда прорисовывается, 320 мс |
| phone | телефонировать | трубка покачивается, дуги «звонят», 520 мс — при наведении |
| send | телеграфировать / отправить | самолётик смещается, 380 мс |
| download | скачать документ | стрелка «падает», 380 мс |
| back-to-top, menu, close, plus, arrow-left, arrow-right, play, copy | интерфейс | без анимации (plus → minus при раскрытии вопроса) |

Когда играет: при первом появлении иконки на экране (долистывание), повторно — при наведении мышью на кнопку или раскрытии вопроса. Вечных циклов нет. При reduced motion всё статично.
