# Готовое: сайт КБ-13 одним файлом

Каждый файл — весь сайт целиком: скрипты, стили, шрифты, картинки и видео внутри.
Не нужны ни сервер, ни VS Code, ни интернет: **скачайте и откройте двойным кликом** (Chrome, Safari, Edge, Firefox).

| Файл | Версия |
| --- | --- |
| `KB13-v3-latest.html` | **v3 «Молния-лента» — последняя, основная** |
| `KB13-v2-groza.html` | v2 «Гроза на бумаге» (скроллворлд «Разрыв») |
| `KB13-v1-first.html` | v1 — первая версия по ТЗ |

Как скачать с GitHub: открыть файл → кнопка «Download raw file» (стрелка вниз справа сверху).

Видео внутри облегчено до 720p (MP4 + запасной WebM), остальное — как на сайте.
Пересобрать файлы: `node scripts/pack-standalone.mjs готовое/KB13-v3-latest.html` в нужной ветке.
